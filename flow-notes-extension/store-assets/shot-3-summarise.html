HTTP caching

Freshness

  • Cache-Control: max-age=3600 lets the browser reuse a response for an hour without contacting the server. [source]

Revalidation

Once stale, the browser asks instead of refetching: it sends the stored ETag (a fingerprint of the response). A 304 Not Modified reply means the copy is still good — headers only, no body. [source]

The misleading one

  • no-cache still stores the response; it means revalidate before every use. To stop storing entirely, use no-store. [source]

In practice

  • Hashed filenames (app.3f9a1c.js) can be cached for a year: a new build gets a new URL, so nothing ever needs invalidating. [source]
